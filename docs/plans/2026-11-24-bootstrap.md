# 第一阶段：本地教学视频工作台

依据：`docs/architecture/project-structure.md`。用户已授权“开始执行”，本阶段直接在当前目录实施。

## 范围

完成 Next.js + Remotion 的本地项目底座、手写教学示例、可编辑预览、SQLite 保存，以及后台导出任务。配音与 AI 服务本阶段不接入，界面明确说明样片暂不含配音。

- [x] 定义小节数据、校验和统一时间计算；先运行失败测试。
- [x] 实现 SQLite 项目保存、乐观版本检查和导出任务快照；验证旧修改不能覆盖新版本。
- [x] 建立共用 Remotion 画面、网页编辑器、项目与任务接口。
- [x] 建立后台 Worker 与 MP4 导出，补齐运行说明和配置。
- [x] 运行测试、类型检查、构建及可用的本地预览／导出检查。

- `npm test`：8 项通过。

- 验收视频：9 秒、1920×1080、H.264，785954 字节；抽取第 0 秒和第 4 秒画面，中文文字、标题、数组显示正常。

## 本阶段关键约束

- 保留现有资料，不移动或批量删除文件。
- 当前不是 Git 仓库，原地搭建；不创建工作树或自动提交。
- SQLite、生成文件与缓存放在 `data/` 或明确忽略的目录。
- Web 和 Worker 同机运行，共用配置与 SQLite；视频任务存储独立快照。
- 无真实密钥也能使用手写样例进行编辑、保存与预览。

## 验收重点

时间计算无重叠；非法输入不能进入数据库；并发修改得到冲突提示；导出绑定固定版本；刷新后能恢复数据；任务进度可查询；导出结果只从应用管理的路径访问。
