# 音色库视觉优化

日期：2026-11-25。范围为现有页面的布局、样式和提示文案；上传、识别、保存和合成接口保持原样。

## 设计与实现

使用项目内 `frontend-design`、`ui-ux-pro-max` 技能设计，并按 `web-design-guidelines` 检查。现有三列并排让音色管理与添加流程混在一起，改为上方管理音色、下方两列添加与校对。

- 音色卡片展示名称、真实参考时长、播放、原文及操作；一个音色时桌面采用紧凑横排，多个音色使用卡片网格，手机单列。
- 顶部增加明确的「添加音色」定位入口、本地服务状态；试听文案收进可展开设置，减少首屏表单。
- 文件选择区使用清晰图标、文件名、格式与大小说明；保持原生文件输入、键盘焦点和屏幕阅读器名称。
- 导入与校对用两步编号，保留最近导入，但限制长列表的显示高度；保存成功、处理中和失败同时使用文字与颜色。
- 使用本地 SVG 图标和装饰音频纹样，不下载字体、图片或新依赖；纹样不表示实际音轨数据，已对辅助技术隐藏。

视觉基准：背景 `#F5F7F4`、纸面 `#FFFFFF`、文字 `#203E32`、主色 `#205C46`、辅助文字 `#63756B`、边线 `#DFE7E1`。延续系统中文字体，标题 30～34px，分区标题 17～19px，表单和辅助信息有明确层级。
