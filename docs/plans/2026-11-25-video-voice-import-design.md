# 独立音色库与视频自动提取设计

目标：在独立页面管理所有音色，上传带声音的视频后提取一段参考声音并自动识别文字，确认后保存为可复用音色。

这是音色库的架构扩展。沿用用户已授权的连续执行方式，不重复等待设计与实施确认。继续在 main 开发，不改个人正式资料，不批量删除。

## 用户流程

首页和课程声音面板提供「音色库」入口。课程中仍可选择音色、应用整片和批量配音；独立页面负责添加、命名、改名、停用和合成试听。课程入口在新标签打开，返回时刷新列表，不丢失课程草稿。

在 `/voices`：选择本机视频或录音 → 预览并选择起始秒数及片段时长 → 提取声音并自动识别 → 听提取的声音、修正文字 → 输入名称保存音色。保存后回到课程即可使用。

支持 MP4、MOV、M4V、WebM、MKV、WAV、MP3；每个源文件最多 200 MB。为得到可用音色，选取单人、清晰、无背景音乐的 3～30 秒片段，默认最多 20 秒。长视频仅处理所选片段，不自动克隆所有说话人，不转写整部视频。

自动识别完成只是待确认草稿，不自动创建音色。支持手动上传录音与原文的既有接口；识别失败时可以重新导入，已有音色不受影响。保存操作幂等，重复点击不增加同一草稿的多个音色。

## 技术路线

优先使用本地 SenseVoice INT8，通过已经安装的 sherpa-onnx 运行；不新增付费 API 或完整 PyTorch。相比云转写，无额度和密钥依赖；相比完整 Whisper 环境，复用现有部署。首次需下载额外识别模型，速度和内存实测后记录。

扩展已有本机 Python 服务：`/health` 增加识别可用状态，`POST /transcribe` 接收标准参考 WAV 的字节，返回文本。SenseVoice 缺失或加载失败不影响 ZipVoice。两类推理共享互斥锁与进程级超时监督；识别最多 120 秒，超时终止推理子进程并重新加载。

媒体流通过 Next.js 写入随机 ID 对应的数据目录，不将 200 MB 文件整体读入内存。上传按实际收到的字节限额，同源检查；文件名只作显示，不作为磁盘路径。根据允许扩展名固定 FFmpeg 解复用器，并检查实际音视频轨。禁止处理远程 URL、网络播放列表或任意客户端路径。

Worker 串行处理导入任务：探测音轨和所选时间范围 → FFmpeg 提取 mono 24k PCM WAV → 本地识别 → 保存可试听的结果及文字。处理结果 3～30 秒，录音哈希与实际时长进入草稿。无音轨、损坏视频、越界片段、静音或无识别文字均给出明确错误，不标记为可保存。

## 数据及接口

`voice_imports` 存储不可变源媒体、片段范围、任务状态、提取音频、识别原文、结果哈希、错误、保存后的音色 ID。源文件和提取音频位于 `DATA_DIR/voice-imports/<id>/`，不上传 Git。失败产物保留，不自动批量删除。

| 接口 | 用途 |
| --- | --- |
| `GET /api/voice-imports/config` | 本地识别服务状态，不返回令牌 |
| `POST /api/voice-imports?filename=…&start=…&duration=…` | 流式上传原文件，创建导入任务 |
| `GET /api/voice-imports` | 最近导入任务，刷新页面可找回 |
| `GET /api/voice-imports/:id` | 查询进度和识别草稿 |
| `GET /api/voice-imports/:id/audio` | 听所选片段 |
| `POST /api/voice-imports/:id/save` | 校对文字和名称后保存音色 |

保存时使用 SQLite 事务固定音色资料并记录导入任务的 voiceId，参考录音不可覆盖。运行中任务重启后失败，用户明确重新导入；既有音色、课程配音和导出链路继续工作。

## 验收

真实本地识别和完整应用分别验证：带声视频提取后识别到内容，修正并保存，在课程中选择并生成声音；协议夹具覆盖错误和保存幂等，不能代替真实识别。测试无音轨、越界、伪装格式、请求超限、进程中断、未装识别模型、文字为空和并发保存。运行全部原有测试、类型检查、构建及独立代码审查，重启并上传 main。同步维护 README 和操作指南。

识别会有错字，必须允许听音频和编辑原文；真人音色相似度仍以用户实际录音试听为准。

官方参考：[SenseVoice 模型](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)、[Python 推理示例](https://github.com/k2-fsa/sherpa-onnx/blob/master/python-api-examples/offline-sense-voice-ctc-decode-files.py)。
