# 第三阶段 DeepSeek 教学草稿设计

状态：用户已于 2026 年 11 月 25 日确认，进入实施计划编写。

## 用户目标与交付结果

在现有教学视频工作台中输入主题、教学对象和期望时长，由 DeepSeek 生成可编辑的小节草稿。用户确认后使用已有的腾讯云配音、预览和 MP4 导出功能完成视频。本阶段不部署本地文字模型。

本次交付包括四项：AI 生成整份课程草稿；新增、删除、复制小节；步骤讲解和左右对比画面；按自然语言要求改写指定小节。

成功标准：输入一个主题后得到可审阅的草稿，确认应用、修改其中一节并生成配音，最终导出完整视频。没有 DeepSeek 密钥时，小节管理、模板和手动制作仍可使用。

## 使用流程

1. 进入项目，在 AI 备课区域填写主题、教学对象和期望时长，点击生成课程草稿。
2. 当前未保存的编辑先保存，然后把任务交给现有后台程序。页面显示等待、生成中、可预览或失败状态。
3. AI 结果先作为独立草稿保存，展示小节标题、讲解和画面内容，不自动覆盖当前课程。
4. 用户点击应用后，课程更新为草稿内容。已有课程替换时明确显示会替换整份课程。
5. 针对某一节，可以输入“讲简单一些，加一个生活例子”等要求，生成并预览这一节的修改。
6. 应用修改后继续使用原有的生成配音、试听和导出按钮。AI 不自动调用配音或导出。

## 小节管理与画面

- 小节数量保持 1～20 个。新增、复制产生新的小节 ID；删除最后一节和超过数量限制的操作被阻止。删除小节仅修改当前课程，已有音频文件保留。
- 原有项目和三种画面模板继续兼容。
- 步骤讲解使用逐行填写的步骤文字，依次呈现要点。
- 左右对比包含可编辑的左右标题和两组要点。增加对应输入框，用户无需编辑 JSON 或代码。
- AI 选择标题、总结、步骤、对比模板，不生成固定的二分查找数组演示，也不执行模型生成的 HTML 或 React 代码。

## DeepSeek 接入

- 使用官方 Chat Completions API，开启 JSON 输出。当前文档中的默认模型为 `deepseek-flash`，通过 `DEEPSEEK_MODEL` 配置。
- 密钥通过 `.env.local` 的 `DEEPSEEK_API_KEY` 提供，只由服务端读取。现有腾讯云密钥不能用于 DeepSeek。
- 页面只展示是否已配置及模型名称；任务记录、日志和浏览器响应中不保存密钥。
- 模型输出只接受受支持的教学数据：标题、小节、文字、画面类型、预估时长和对比内容。系统分配小节 ID，单节改写保留原 ID 和音色设置。
- 输出经过长度、类型、小节数量和字段校验后才可预览。空结果、截断、错误格式和接口错误显示可理解的错误提示。
- 一次主动生成只提交一次模型请求，不自动重试。DeepSeek 调用按该账号的实际额度及计费规则处理，本阶段不承诺免费，也不主动充值或购买服务。

官方依据：[首次调用](https://api-docs.deepseek.com/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 数据与任务

- 沿用 Node.js、Next.js、SQLite 和现有单 Worker，不新增数据库或大型运行依赖。
- AI 任务单独存表，记录请求、项目版本、源课程快照、状态、结果和错误信息。刷新页面后可重新读取任务与草稿。
- 重复提交同一个尚未结束的请求，复用已有任务。重启后台程序后，中断的请求标记失败，用户检查用量后自行重试。
- 应用草稿前检查项目版本。生成期间课程已保存为新版本时，阻止直接覆盖，保留生成结果供查看。
- 应用后的撤销仅在课程没有后续保存时生效，撤销操作生成新版本，不回退版本号。它恢复应用前的课程，不删除音频文件。
- 用户可以放弃未应用的结果。AI 失败或放弃草稿不改变原课程。

## 验证与发布

1. 对小节边界、模板字段、AI 结果校验、任务去重、应用及撤销的版本冲突编写测试。
2. 用本机 HTTP 协议夹具验证 DeepSeek 请求、失败不自动重试、草稿预览后应用、单节改写和撤销，不消耗真实模型额度。
3. 检查步骤与对比画面的预览及 MP4 导出，保留原有配音导出测试。
4. 真实 DeepSeek 验证需先配置密钥。配置缺失时明确报告未验证的范围，不用模拟结果冒充真实生成。
5. 更新 `docs/操作指南.md` 与 README。完成验证后重启工作台，保留已有项目与腾讯云配置。

## 本阶段边界

本阶段实现固定流程的 AI 备课助手。自由生成 HTML 动画、逐句动作对齐、资料上传检索和云端多人使用留到后续阶段。
