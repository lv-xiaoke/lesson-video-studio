# 知帧教学视频工作台操作指南

最后更新：2026 年 11 月 25 日。

当前制作流程：**AI 起草或手动编写 → 审核并应用 → 生成腾讯云配音 → 预览 → 导出 MP4**。AI 负责文字与结构，画面使用固定模板；不会自动生成任意 HTML。

日常使用打开 [教学视频工作台](http://127.0.0.1:3000)。如果无法打开，请先看下方的「启动服务」。首次安装及密钥配置见 [README](../README.md#环境与安装)。

## 从创建项目到导出视频

### 第一步 创建项目

1. 打开工作台首页。
2. 在「视频标题」中输入这条视频的名称。
3. 点击「进入制作」。

新项目会载入三个小节的二分查找示例。接下来可以直接编辑这份示例，也可以替换成自己的教学内容。第一次建议先制作一条约半分钟的短视频。

### 第二步 用 AI 生成草稿（也可以跳过）

首次使用，在本机 `.env.local` 填入 `DEEPSEEK_API_KEY`，保留 `DEEPSEEK_MODEL=deepseek-flash`，重启网页和后台服务。腾讯云配音密钥保持原样，详细配置见 [README](../README.md#配置-deepseek-写稿可选)。不要把密钥发到聊天或写入项目文件。

1. 在编辑器中间的「AI 备课助手」填写教学主题、教学对象和期望时长。
2. 点击「生成课程草稿」，等待后台完成。每次生成会调用 DeepSeek API 并消耗额度。
3. 查看草稿中的每节画面文字与讲解稿，确认知识点正确、适合学习对象。
4. 满意后点击「应用并替换整份课程」；不满意可「放弃这份结果」，再调整要求生成。

「查看草稿记录」可以切换最近保留的生成结果，包括已应用或已撤销的草稿。旧草稿仍可阅读，能否应用由当前课程版本决定。

生成完成不会改动当前课程，也不会调用配音。**应用整课会替换目前的小节**；没有后续编辑时，可以点击「撤销这次应用」恢复。课程已被修改时，旧草稿禁止直接覆盖，需重新生成。

期望时长只是写稿参考，不保证视频恰好达到该秒数；最终以实际配音长度为准。未配置 DeepSeek 时可以继续手动制作。当前已用本机模拟接口验收流程，真实模型效果待填写密钥后检查。

### 第三步 编辑每个小节

点击左侧「教学小节」中的一节，在右侧填写内容：

| 页面字段 | 填什么 | 示例 |
| --- | --- | --- |
| 视频标题 | 整条视频的名称 | 什么是二分查找 |
| 小节标题 | 这一段的标题 | 每次少找一半 |
| 屏幕文字 | 展示在画面上的要点，建议不超过三行 | 从有序数组开始 |
| 讲解稿 | 实际朗读的完整句子 | 如果数字已经排好顺序，每次检查中间的数字，就能缩小查找范围。 |
| 画面类型 | 选择这一段使用的画面模板 | 开场标题、数组演示、知识总结、步骤讲解、左右对比 |

「屏幕文字」负责让人看懂，「讲解稿」负责把内容讲清楚，两者可以采用不同表述。

**数组演示目前固定为二分查找示例。** 如果讲其他主题，把这一节的「画面类型」改为「开场标题」或「知识总结」，避免出现不相关的数组动画。

用左侧「新增小节」「复制当前节」「删除当前节」管理内容，用「上移」「下移」调整顺序。至少保留一节，最多二十节；删除需确认，旧配音文件仍保留。

步骤讲解：屏幕文字每行一个步骤，最多五行，每行最多八十字。左右对比：分别填写两侧标题和要点，每侧最多四条。画面尽量用短句，详细解释写在讲解稿中。

只想调整一节时，先选中它，在「AI 备课助手」填写修改要求，点击「生成此节改写草稿」。预览后点击「应用到此小节」，其余小节保持原样。正在生成时可以编辑；如果编辑后保存，旧结果不能覆盖新版本。应用、撤销期间编辑会短暂锁定，避免请求返回时覆盖刚输入的内容。

### 第四步 选择声音并保存

1. 在右侧「小节配音」中选择「腾讯云精品音色」。
2. 第一次可以保留默认的「智瑜 · 情感女声」，语速保持约 1.0 倍。
3. 点击右上角「保存项目」，确认状态显示「已保存」。

音色和语速按小节设置。希望全片声音一致时，各小节选择相同的音色和语速。

### 第五步 生成配音并试听

1. 先选择一个小节，点击「生成此节配音」。
2. 等待状态变为「已就绪」。
3. 用小节配音区域的音频播放器试听，检查语气、术语读音和停顿。
4. 满意后，点击预览区下方的「生成缺失配音」，补齐其他小节。

生成配音会调用腾讯云 API 并消耗对应资源包额度。较长讲解会自动分段合成，无需手动拆成多条音频。

页面中的「讲解与声音」会显示配音就绪的小节数量。三节示例全部完成时，应显示 **3 / 3 节配音已就绪**。

### 第六步 预览整条视频

1. 保持勾选「预览与导出使用配音」。
2. 在画面播放器中播放整条视频。
3. 检查标题、屏幕文字、讲解顺序和声音是否合适。

配音就绪后，画面时长会按实际音频自动匹配，并保留结尾停顿。此时无需手动估算讲解要读多少秒。

如果需要调整内容，按下方「修改之后怎样更新」处理，再次预览。

### 第七步 导出并下载

1. 确认每个小节的配音都已就绪。
2. 点击右上角「导出带配音视频」。
3. 在「视频导出」区域等待状态从「等待后台制作」变为「正在制作」，最后变为「制作完成」。
4. 点击「下载 MP4」，保存到电脑。

导出使用点击按钮时保存的内容和配音版本。随后继续修改项目，不会改变这次导出的内容；需要更新视频时重新导出。

制作期间可以关闭网页，后台程序仍需保持运行，电脑不能关机。

## 修改之后怎样更新

| 修改了什么 | 接下来怎么做 |
| --- | --- |
| 视频标题、小节标题、屏幕文字或小节顺序 | 保存并重新预览，匹配的配音可以继续复用 |
| 某一节的讲解稿、音色或语速 | 生成该节的新配音，试听后重新导出 |
| 希望换一种朗读效果 | 调整音色或语速，再生成配音 |
| 同样的文字和声音设置，希望重新合成一次 | 点击「重新生成此节配音」，会再次调用腾讯云 |

需要更新的旧配音会保留原文件，但不会进入当前带配音预览和新导出。只重做一节时，其他匹配的小节配音仍可复用。

## 启动服务

网页服务负责打开工作台，后台程序负责 AI 写稿、配音和视频导出。两者都需要运行。

**网页已经能打开、任务也正常执行时，无需再次启动。** 重启电脑或服务已退出时，可以手动按下面操作。

在项目目录打开第一个 PowerShell 终端：

```powershell
Set-Location 'D:\my_develop\A_work_program\AI_create_vidio'
npm run start
```

看到本机地址及就绪提示后，打开 [工作台](http://127.0.0.1:3000)。`npm run start` 使用已构建的版本；如果首次安装或源代码有更新，先按 README 执行构建。

在相同项目目录打开第二个 PowerShell 终端：

```powershell
Set-Location 'D:\my_develop\A_work_program\AI_create_vidio'
npm run worker
```

看到「知帧后台制作程序已启动，等待导出任务」后，即可生成配音和导出视频。手动启动时保持这两个终端运行。**同一数据目录只运行一个后台制作程序。**

本机密钥保存在项目根目录的 `.env.local`。修改配置后需要重启这两个服务；已有配置时不要用 `.env.example` 覆盖 `.env.local`。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 工作台网址打不开 | 确认网页服务已启动，再访问 `http://127.0.0.1:3000` |
| 显示「尚未配置腾讯云」 | 检查 `.env.local` 中的 `TTS_PROVIDER=tencent`、`TENCENT_SECRET_ID` 和 `TENCENT_SECRET_KEY`，保存后重启两个服务 |
| 配音一直「等待后台合成」，或导出一直「等待后台制作」 | 确认后台制作程序正在运行，查看它所在终端的提示 |
| 提示无法获取后台进程锁 | 通常已有一个后台制作程序在运行，使用现有进程，不要重复启动 |
| 配音提示资源包耗尽、过期或欠费 | 到腾讯云控制台查看基础/精品音色资源包及有效期，保持后付费关闭 |
| 配音失败或超时 | 阅读页面错误提示，先核对腾讯云调用用量，再点击「重试此节配音」；失败不会自动重试，重试可能再次消耗额度 |
| 导出提示某节配音缺失或已过期 | 为对应小节生成匹配的新配音，再导出 |
| 预览或视频没有声音 | 确认勾选「预览与导出使用配音」、每节配音已就绪，以及播放器和系统没有静音 |

## 当前功能范围

目前支持 DeepSeek 整课起草与单节改写、人工审核后应用与受版本保护的撤销、小节增删复制排序、五种画面模板、腾讯云或 MiniMax 分节配音、音频试听、按配音长度安排画面，以及导出带声音的 MP4。

根据主题自动生成任意 HTML 动画、逐字高亮字幕和多人登录尚未实现。生成稿需要人工检查知识正确性，配音及导出仍由你明确点击。
