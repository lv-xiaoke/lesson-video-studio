# 知帧教学视频工作台操作指南

最后更新：2026 年 11 月 25 日。

当前制作流程：**AI 起草或手动编写 → 审核并应用 → 选择云端或本地配音 → 预览 → 导出 MP4**。本地 ZipVoice 无配音 API 费用，支持保存并复用自己的音色。AI 负责文字与结构，画面使用固定模板；不会自动生成任意 HTML。

日常使用打开 [教学视频工作台](http://127.0.0.1:3000)。如果无法打开，请先看下方的「启动服务」。首次安装及密钥配置见 [README](../README.md#环境与安装)。

顶部四步导航是当前版本的操作入口：**生成草稿 → 编辑确认 → 生成配音 → 预览导出**。可以随时返回前一步修改；切换步骤不会自动调用 AI、配音或导出。默认打开「编辑确认」，中间直接显示视频预览。

## 从创建项目到导出视频

### 第一步 创建项目

1. 打开工作台首页。
2. 在「视频标题」中输入这条视频的名称。
3. 点击「进入制作」。

新项目会载入三个小节的二分查找示例。接下来可以直接编辑这份示例，也可以替换成自己的教学内容。第一次建议先制作一条约半分钟的短视频。

### 第二步 用 AI 生成草稿（也可以跳过）

首次使用，在本机 `.env.local` 填入 `DEEPSEEK_API_KEY`，保留 `DEEPSEEK_MODEL=deepseek-flash`，重启网页和后台服务。腾讯云配音密钥保持原样，详细配置见 [README](../README.md#配置-deepseek-写稿可选)。不要把密钥发到聊天或写入项目文件。

1. 点击顶部「生成草稿」，在「AI 备课助手」填写教学主题、教学对象和期望时长。
2. 点击「生成课程草稿」，等待后台完成。每次生成会调用 DeepSeek API 并消耗额度。
3. 查看草稿中的每节画面文字与讲解稿，确认知识点正确、适合学习对象。
4. 满意后点击「应用并替换整份课程」；不满意可「放弃这份结果」，再调整要求生成。

「查看草稿记录」可以切换最近保留的生成结果，包括已应用或已撤销的草稿。旧草稿仍可阅读，能否应用由当前课程版本决定。

生成完成不会改动当前课程，也不会调用配音。**应用整课会替换目前的小节**；没有后续编辑时，可以点击「撤销这次应用」恢复。课程已被修改时，旧草稿禁止直接覆盖，需重新生成。

期望时长只是写稿参考，不保证视频恰好达到该秒数；最终以实际配音长度为准。未配置 DeepSeek 时可以继续手动制作。当前已通过模拟流程与一次真实 DeepSeek 整课生成测试，生成稿仍需要人工检查。

### 第三步 编辑每个小节

点击顶部「编辑确认」，再选左侧的一节。右侧通过「讲解」「画面」「声音」三个标签切换编辑内容：标题和讲解稿在「讲解」，模板和屏幕文字在「画面」，音色与试听在「声音」。中间显示当前视频预览。

| 页面字段 | 填什么 | 示例 |
| --- | --- | --- |
| 视频标题 | 整条视频的名称 | 什么是二分查找 |
| 小节标题 | 这一段的标题 | 每次少找一半 |
| 屏幕文字 | 展示在画面上的要点，建议不超过三行 | 从有序数组开始 |
| 讲解稿 | 实际朗读的完整句子 | 如果数字已经排好顺序，每次检查中间的数字，就能缩小查找范围。 |
| 画面类型 | 选择这一段使用的画面模板 | 开场标题、数组演示、知识总结、步骤讲解、左右对比 |

「屏幕文字」负责让人看懂，「讲解稿」负责把内容讲清楚，两者可以采用不同表述。

**数组演示目前固定为二分查找示例。** 如果讲其他主题，把这一节的「画面类型」改为「开场标题」或「知识总结」，避免出现不相关的数组动画。

用左侧「新增小节」「复制当前节」「删除当前节」管理内容，用「上移」「下移」调整顺序。至少保留一节，最多二十节；删除需确认，旧配音文件仍保留。

步骤讲解：屏幕文字每行一个步骤，最多五行，每行最多八十字。左右对比：分别填写两侧标题和要点，每侧最多四条。画面尽量用短句，详细解释写在讲解稿中。

只想调整一节时，先选中它，在「AI 备课助手」填写修改要求，点击「生成此节改写草稿」。预览后点击「应用到此小节」，其余小节保持原样。正在生成时可以编辑；如果编辑后保存，旧结果不能覆盖新版本。应用、撤销期间编辑会短暂锁定，避免请求返回时覆盖刚输入的内容。

### 第四步 选择声音并保存

1. 点击右侧「声音」，在「配音服务」选择「腾讯云」「MiniMax」或「本地 ZipVoice」。仅影响当前课程。
2. 腾讯云可选择智瑜等现有音色；本地模式从「我的本地音色」选择，无音色时按下方「添加本地音色」操作。
3. 语速先保持 1.0 倍。希望整片一致时，点击「将此音色和语速应用到全部小节」。
4. 点击右上角「保存项目」，确认状态显示「已保存」。生成配音时也会先保存。

音色和语速按小节设置。切换服务后需重新选择音色，旧服务音频不会混入新服务导出。正在生成的任务仍使用提交时的服务。

### 第五步 生成配音并试听

1. 点击顶部「生成配音」，或右上角「下一步：生成配音」。
2. 点击「为全部小节生成配音（N 节）」。已生成过部分配音时，按钮会改为「补齐配音（N 节）」，有效配音不会重复合成。
3. 等待整片进度显示全部就绪。左侧每节会标出「未配音、等待配音、生成中、已配音、需更新、配音失败」。
4. 选择一节，在右侧「声音」中试听，检查语气、术语读音和停顿；不满意时只重做该节。

第一次也可以先在右侧点击「生成此节配音」试听，满意后再批量补齐。只点击步骤导航不会生成配音，必须明确点击生成按钮。

选择腾讯云或 MiniMax 时，生成配音会调用对应 API 并消耗额度。本地 ZipVoice 在电脑上生成，不消耗厂商配音额度；首次需下载模型。较长讲解会自动分段合成，无需手动拆成多条音频。

页面中的「整片配音」会显示就绪数量和进度条。三节示例全部完成时，应显示 **3 / 3 节已就绪**。

### 第六步 预览整条视频

1. 点击「预览导出」，保持勾选「预览与导出使用配音」。
2. 在画面播放器中播放整条视频。
3. 检查标题、屏幕文字、讲解顺序和声音是否合适。

配音就绪后，画面时长会按实际音频自动匹配，并保留结尾停顿。此时无需手动估算讲解要读多少秒。

如果需要调整内容，按下方「修改之后怎样更新」处理，再次预览。

### 第七步 导出并下载

1. 在「预览导出」检查每节配音是否就绪。缺失时页面会列出小节标题，点击「去补齐配音」返回配音步骤；需要无声版本时，可取消勾选「预览与导出使用配音」。
2. 点击右上角「导出带配音视频」。
3. 在「导出记录」区域等待状态从「等待后台制作」变为「正在制作」，最后变为「制作完成」。
4. 点击「下载 MP4」，保存到电脑。

导出使用点击按钮时保存的内容和配音版本。随后继续修改项目，不会改变这次导出的内容；需要更新视频时重新导出。

制作期间可以关闭网页，后台程序仍需保持运行，电脑不能关机。

## 修改之后怎样更新

| 修改了什么 | 接下来怎么做 |
| --- | --- |
| 视频标题、小节标题、屏幕文字或小节顺序 | 保存并重新预览，匹配的配音可以继续复用 |
| 某一节的讲解稿、音色或语速 | 生成该节的新配音，试听后重新导出 |
| 希望换一种朗读效果 | 调整音色或语速，再生成配音 |
| 同样的文字和声音设置，希望重新合成一次 | 点击「重新生成此节配音」，使用当前选定的配音服务 |

需要更新的旧配音会保留原文件，但不会进入当前带配音预览和新导出。只重做一节时，其他匹配的小节配音仍可复用。

## 添加与复用本地音色

1. 点击首页或编辑器顶部「音色库」，进入独立的 [音色管理页面](http://127.0.0.1:3000/voices)。从课程打开时会使用新标签，原草稿保留。
2. 点击「添加音色」定位到下方「导入声音素材」，选择带声音的视频或录音；支持 MP4、MOV、M4V、WebM、MKV、WAV、MP3，最大 200 MB。
3. 播放源文件，填写「从第几秒开始」「提取多少秒」，选择 3～30 秒的单人清晰讲话，建议 10～20 秒。只识别这段声音，不转写整部视频。
4. 点击「提取声音并自动识别」。后台完成后，「检查声音与原文」会显示可试听的参考声音和自动识别原文。可关闭页面后回来，从「最近导入」找回。
5. 听提取结果，修正错字或漏字，填写音色名称，点击「确认原文并保存音色」。识别草稿不会自动成为音色，重复保存不会创建多个音色。
6. 上方「我的音色」卡片中可以查找、改名、停用和「合成试听」；需要更换试听文案时展开「自定义合成试听文字」。确认效果后返回课程，在「声音」选择「本地 ZipVoice」及对应音色，再点击「将此音色和语速应用到全部小节」。返回编辑器会自动刷新音色；也可以手动点击「刷新音色列表」。

已有 WAV/MP3 及准确原文时，可展开「已有录音和文字？手动添加」，跳过识别直接保存。手动录音仍限制 3～30 秒、最大 10 MB。

音色可改名或停用。更换参考录音和原文时创建新音色；停用只隐藏新任务选项，已有录音、历史音频和排队任务保留。被停用音色的已有有效配音仍可导出，需要重新配音时先选择有效音色。系统不会自动改用付费厂商。

本机已安装模型；首次使用自己的音色时还需要上传自己的参考录音。目前未附带真人音色，已有腾讯云音色可以直接选择。

识别在本机完成，无新增 API 密钥或转写费用。本机实测从 6 秒测试视频提取并识别约 1.3 秒；不同素材和电脑速度会不同。自动文字可能有错字或漏字，务必对照声音检查后保存；这也有助于后续配音效果。

## 启动服务

日常推荐在项目目录运行下面一个命令，它会复用仍在运行的本项目进程，并补启动缺失的网页或 Worker；已安装的本地引擎也会启动。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local-services.ps1
```

首次安装本地引擎需要 Python 3.11 与 FFmpeg，运行 `python scripts/setup-zipvoice.py`，详细说明见 README。本地引擎单独启动命令为 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-zipvoice.ps1`。模型首次需联网下载，以后可以离线配音；DeepSeek 写稿仍调用 API。

此前只装过配音模型的电脑，重新运行初始化脚本会补充 SenseVoice 识别模型（额外下载约 163 MB），再运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-zipvoice.ps1 -Restart`。重启前要等所有任务完成，脚本会检查队列和进程身份。本次升级已经替你完成安装和重启。

以下也保留分别手动启动网页和 Worker 的方式：

网页服务负责打开工作台，后台程序负责 AI 写稿、配音和视频导出。两者都需要运行。

**网页已经能打开、任务也正常执行时，无需再次启动。** 重启电脑或服务已退出时，可以手动按下面操作。

在项目目录打开第一个 PowerShell 终端：

```powershell
Set-Location 'D:\my_develop\A_work_program\AI_create_vidio'
npm run start
```

看到本机地址及就绪提示后，打开 [工作台](http://127.0.0.1:3000)。`npm run start` 使用已构建的版本；如果首次安装或源代码有更新，先按 README 执行构建。

在相同项目目录打开第二个 PowerShell 终端：

```powershell
Set-Location 'D:\my_develop\A_work_program\AI_create_vidio'
npm run worker
```

看到「知帧后台制作程序已启动，等待导出任务」后，即可生成配音和导出视频。手动启动时保持这两个终端运行。**同一数据目录只运行一个后台制作程序。**

本机密钥保存在项目根目录的 `.env.local`。修改配置后需要重启这两个服务；已有配置时不要用 `.env.example` 覆盖 `.env.local`。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 工作台网址打不开 | 确认网页服务已启动，再访问 `http://127.0.0.1:3000` |
| 本地服务未启动或模型未就绪 | 运行上述启动脚本，等待页面自动刷新服务状态；日志位于 `DATA_DIR/zipvoice/` |
| 本地列表没有音色 | 进入独立音色库，上传视频/录音并识别、校对、保存，再返回课程选择 |
| 视频提示没有可用音轨 | 文件本身不含可解码的声音，选择带声版本或单独音频 |
| 提示片段超出范围或没有完整音轨 | 缩短选取时间，保证所选整段都有可用音轨 |
| 识别原文有错误 | 在中间的原文框里对照音频修改，再保存音色 |
| 本地识别未就绪，但配音正常 | 检查 SenseVoice 是否已安装；原生识别异常时引擎会降级保留配音，队列空闲后用 `-Restart` 重启 |
| 本地生成较慢 | 本机实测 101 字约 35～39 秒；先制作一小节试听，保持电脑运行，不必重复点击 |
| 本地生成超时 | 推理子进程会被终止并重新加载；等待服务恢复后手动重试，不会自动调用收费 API |
| 显示「尚未配置腾讯云」 | 检查 `.env.local` 中的 `TTS_PROVIDER=tencent`、`TENCENT_SECRET_ID` 和 `TENCENT_SECRET_KEY`，保存后重启两个服务 |
| 配音一直「等待后台合成」，或导出一直「等待后台制作」 | 确认后台制作程序正在运行，查看它所在终端的提示 |
| 提示无法获取后台进程锁 | 通常已有一个后台制作程序在运行，使用现有进程，不要重复启动 |
| 配音提示资源包耗尽、过期或欠费 | 到腾讯云控制台查看基础/精品音色资源包及有效期，保持后付费关闭 |
| 配音失败或超时 | 阅读页面错误提示，先核对腾讯云调用用量，再点击「重试此节配音」；失败不会自动重试，重试可能再次消耗额度 |
| 导出提示某节配音缺失或已过期 | 为对应小节生成匹配的新配音，再导出 |
| 预览或视频没有声音 | 确认勾选「预览与导出使用配音」、每节配音已就绪，以及播放器和系统没有静音 |

## 当前功能范围

目前支持 DeepSeek 起草与改写、审核应用与撤销、小节管理、五种画面模板、三种配音服务、批量生成、独立音色库、视频片段提取和本地自动识别、音色试听，以及按配音时长导出带声 MP4。真人音色效果需要用实际录音试听；模型验收使用明确标记的合成测试参考。

根据主题自动生成任意 HTML 动画、逐字高亮字幕和多人登录尚未实现。生成稿需要人工检查知识正确性，配音及导出仍由你明确点击。
